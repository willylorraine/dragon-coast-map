# Драконье побережье

Интерактивная карта мира шоу «Стражи беспорядка» (YouTube-канал «Как кости лягут»).

Свиток разворачивается, море живое (WebGL), компас крутится, по городам проходят золотые блики, левиафан и кракен всплывают из воды. Колесо мыши приближает, карту можно двигать, по клику на город камера подлетает к нему.

География взята из оригинальной карты один в один; иконки, корабли, пергамент и валики свитка нарисованы в Higgsfield в стиле иконок шоу.

## Версия 2

Что добавлено поверх карты коллеги (ТЗ лежит в `map/TZ.md` проекта lore-content, журнал разработки в `map/DEVLOG.md`):

- **Карточка места.** Клик или тап по городу, острову, надписи моря и кораблю героев открывает карточку с текстом из вики, ссылкой «Читать в вики» и связанными статьями. У восьми мест, которых нет в вики, вместо статьи один абзац в стиле вики по тому, что нарисовано на карте мастера; строки статуса, ссылки в вики и связанных статей у них нет.
- **Указатель мест** («Все места»): 14 пунктов в трёх группах по местности («Север», «Горы», «Море»), поиска нет.
- **Альбом (телефон на боку).** Кнопка «Все места» стоит рядом с названием и открывает указатель той же панелью справа, что и карточку. В нижнем листе телефона и планшета тап по ручке переключает ярлык и указатель так же, как свайп.
- **Подписи на узкой бумаге крупнее.** Когда бумага уже, чем на 1440×900 (877 px), кегль подписей на карте растёт через `--lbl-k` (до 1,45), раскладка подписей без наложений считается заново (`DCM.relabel()`). Подпись корабля нажимается так же, как сам корабль.
- **Глубокие ссылки** `?place=<слаг>` и кнопка «Поделиться». Старое написание `?place=klatr-kov` ведёт на `klatter-kouv`.
- **Телефон и планшет.** Своя раскладка в портрете и альбоме: бумага занимает всю высоту сцены, карту двигают пальцем и приближают щипком, карточка и указатель живут в нижнем листе, кнопки зума в рельсе под большим пальцем. В портрете карта сразу открыта на весь экран (потолка по высоте бумаги нет); отдалить можно до того, как вся карта поместится по ширине экрана (кнопка «Вся карта», «−» и щипок доводят до этого масштаба).
- **Ввод на одной модели указателя** (Pointer Events): тап, перетаскивание, щипок, колесо. Клавиатура: Tab по местам с запада на восток, стрелки, плюс, минус, 0, Enter, Esc.
- **Движение после разворота успокаивается.** Живут вода, корабли и чудища; блики срабатывают один раз; `prefers-reduced-motion` даёт неподвижную карту; кнопка «Успокоить море» останавливает всё.
- **Лёгкая загрузка.** WebP вместо PNG: первая загрузка около 3,8 МБ вместо 15,4 МБ, сначала виден свёрнутый свиток. Без WebGL показывается кадр шейдера без оверлея, после потери контекста карта восстанавливается.

Режимы `?video` и `?alpha` (для роликов шоу) рисуют то же, что версия 007cc11: свои ассеты PNG и JPG, никакого интерфейса, `window.renderAt(t)` и `window.__ready` как раньше. Отличие только в переименованных подписях («Клаттер-Коув», «Солэйн») и в новой иконке Брайтвотера.

## Файлы

| Путь | Что это |
|---|---|
| `index.html` | оболочка и движок: WebGL-шейдер, SVG-оверлей, свиток, таймлайн разворота, `renderAt` |
| `ui.js`, `ui.css` | интерфейс: раскладка, камера, ввод, панель и карточка, указатель, ссылки (в `?video` не грузятся) |
| `data/places.json`, `data/strings.json` | места и строки интерфейса; строки заполняются дословно из `map/TEXTS.md` |
| `sprites/`, `tex_*`, `brand/` | иконки, текстуры, логотип: оригиналы PNG и JPG и рядом WebP |
| `tex_fallback.webp` | кадр шейдера для браузеров без WebGL |
| `fonts/` | Epos и Spectral 400 и 500 (лицензия шрифта Spectral в `OFL.txt`) |
| `og-image.jpg`, `favicon.svg` | превью ссылки 1200×630 и значок (как у вики) |
| `tools/` | `convert-assets.py` (WebP из оригиналов), `check-places.mjs` (проверка данных), `golden.py` (эталонные кадры `?video`), `make-og.py` (превью ссылки) |

## Как запустить

Карте нужен http-сервер (WebGL-текстуры с `file://` не грузятся):

```
python -m http.server 8792
```

и адрес `http://127.0.0.1:8792/`. Режимы: `?video`, `?video&alpha`, глубокая ссылка `?place=ingrira`.

## Проверки

```
python map/tests/test_v2.py        # автотесты раздела 9 ТЗ (A–J) и дополнительные K; отчёт map/tests/v2_results.md
node tools/check-places.mjs        # данные против TEXTS.md и вики
python tools/convert-assets.py     # пересоздать WebP из оригиналов
python tools/make-og.py            # пересоздать og-image.jpg
```

Тесты идут в Python Playwright (headless Chromium, SwiftShader), поднимают свой сервер на порту 8792.
